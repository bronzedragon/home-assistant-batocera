# Development assets

Non-installable supporting resources for the Home Assistant Batocera project.

- [scripts/](scripts/) — Batocera-side helper scripts, Avahi/mDNS service launchers, and local development utilities.
- [images/](images/) — artwork drafts, screenshots, diagrams, and design references.

These files are **not part of the Home Assistant integration** and are not automatically installed by HACS. Installable integration code and branding remain under `custom_components/batocera/`.

Keep secrets, credentials, private network data, ROM files, and copyrighted game assets out of this public repository. Prefer portable scripts that discover device-specific settings dynamically.
