# Supporting scripts

Place optional Batocera host-side scripts and development utilities here.

Examples:
- Avahi advertiser for `_batocera._tcp`, with dynamically detected MAC, model, and Wake-on-LAN capabilities
- API diagnostic scripts
- Local testing helpers

Scripts stored here are reference/deployment assets, **not Home Assistant integration modules**. Document installation, required dependencies, persistence across Batocera updates, and safe usage for each script.
